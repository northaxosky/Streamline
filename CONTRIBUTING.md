# Contributing to Streamline

We welcome bug reports and pull requests. Open a pull request with your proposed
change and we will review it and integrate it on our end — your change will appear
in a subsequent release.

## Reporting a bug

Open an issue. The more of this you can give us, the faster it moves:

- Streamline version
- GPU and driver version
- OS and build
- Graphics API (DirectX 11/12, Vulkan) and which SL plugins are loaded
- What you expected, what happened instead
- Steps to reproduce, ideally a minimal repro
- Relevant logs (`sl.log`)

## Security issues

**Do not open a public issue for a security vulnerability.** Report it through
NVIDIA's PSIRT process at
<https://www.nvidia.com/en-us/security/report-vulnerability/>.

## Contributor License Agreement

**We need a signed CLA on file before we can take a code contribution.**

1. Read [`CLA.md`](CLA.md) in the root of this repository.
2. Complete **one** of the two options at the bottom — individual, or on behalf of
   your employer if you are contributing in the course of your work.
3. Fill in every field of the option you chose. **The GitHub login is required** —
   it is how we match a signed agreement to a pull request.
4. Email the completed agreement to **DLSS-Github [at] nvidia.com**.

You only need to do this once; it covers your future contributions. If your company
would rather sign once for everyone, a corporate CLA works — email the same address
and tell us which GitHub logins it covers.

## Licensing of contributions

By contributing, you agree that your contribution is licensed under the terms in
